# Каноническая таблица оценки

Единственный файл с цифрами оценки для презентации. Сгенерирован `cd app && uv run poe eval` (`eval/report.py`), git `29dda4a`, прогоны с меткой `offline` (офлайн: шаблонный текст, без сети; погода, воздух и время берутся из кейса, дорога — по прямой × 1.3). git — короткий sha последнего коммита, менявшего `app/walks`, `app/eval` (без `results`), `data`, `collect`; `+uncommitted` — в этих путях есть незакоммиченные изменения.

- **main** — основной набор, на нём подгонялись правила ранжирования; **holdout** — отдельный набор, написан отдельно, правила потом тоже подгонялись под его провалы. **holdout2** — слепой на момент замера d5e4b05: poi 20.8% / poi.enriched 20.8% без нарушений; после исправлений общих классов ошибок — уже не слепой, его текущие числа показывают прогресс, а не обобщение. Набор: 24 кейсов, написаны другой моделью без доступа к коду (blind-glm, 2026-10-17; коммит `1d153eb`); **holdout3** — 24 кейсов, написаны по одному `eval/SCHEMA.md`, без доступа к коду и уже после исправлений (blind-glm-v2, 2026-10-17; коммит `a21c70f`); это число обобщения. **abstain** — кейсы в заведомо скудных или невозможных ситуациях, где честный ответ — «рядом ничего подходящего нет» либо помеченный компромисс. Число кейсов — в заголовке колонки.
- **padding** — доля рекомендаций, добранных расширением радиуса (`radius_factor > 1`), другой категорией (back-fill) или заменой из-за погоды (`substituted`: при морозе или смоге место в помещении вместо уличного — парка, смотровой, открытой достопримечательности; категория вне запроса, но не нехватка мест в данных), а не заявленным радиусом/категорией; берётся из поля `padding` результата пайплайна. Показана на карточке меткой («чуть дальше» / «другая категория»); замена из-за погоды помечена так же, как «другая категория», и считается отдельной строкой.
- **honest_abstain_rate** (только abstain) — кейс пройден, если рекомендаций нет или ни одна не выдаёт несовпадение за совпадение: компромисс помечен (padding-метка, «Категория вне вашего запроса», «Часы работы в данных неизвестны», «Wi-Fi/розетки не подтверждены»). Кейсы abstain задуманы так, что обычного совпадения быть не должно; `н/п` — метрика для набора не определена.
- **holdout2 и бюджет времени.** Кейсов с нарушением `over_budget` (маршрут длиннее `budget_min` кейса; маршрут заполняет бюджет, который система взяла из запроса или по умолчанию): poi: 15 из 24, poi.enriched: 15 из 24. Coverage и «кейсов без нарушений» этого набора считаются вместе с ним; число без `over_budget` — в `summary_*_holdout2_offline.md` (таблица «Нарушения»).
- **Аудит ожиданий holdout2.** 4 из 24 ожиданий `budget_min` противоречат тексту запроса по независимому аудиту ([`app/eval/holdout2_audit.json`](../holdout2_audit.json)): `h2-05`, `h2-10`, `h2-16`, `h2-17`; ещё 3 спорные. Цифры не пересчитывались.
- **holdout3 — честное число обобщения**: кейсов без нарушений — poi: 50.0%, poi.enriched: 54.2%. Набор написан после исправлений и ни разу не использовался для подгонки; провалы разобраны в `summary_*_holdout3_offline.md`.
- Допущения (бюджет времени по умолчанию, доля времени на дорогу, радиусы, скорость): раздел «Допущения» в `docs/scenarios.md`.
- **н/п** — метрика не определена: для набора (см. выше) или для офлайн-прогона, где нет модели (недоступность цепочки ИИ, откат из-за проверки ответа ИИ, latency ответа ИИ). Latency пайплайна в этих колонках — время шаблонного пути, не ИИ.
- ИИ-режим в основную таблицу не входит: он измерен отдельно, на другом наборе кейсов (раздел «ИИ-режим» ниже), и с числами таблицы не смешан.
  Исторический стресс-прогон 16.10 описан в конце файла и тоже с числами таблицы не смешан.
