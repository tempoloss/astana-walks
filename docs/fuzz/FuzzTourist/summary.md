# FuzzTourist — 60 запросов туриста × 2 режима (offline / AI), 2026-10-17

- Запросы: `queries.jsonl` (60; ru/en/kk/mix; опечатки, сленг, constraints: дети, коляска, халяль, вег, бюджет, ночь, холод).
- Сырые выходы: `outputs/<id>_<mode>.txt` (120 файлов), тайминги: `timing.jsonl`.
- Проблемы: `findings.jsonl` (30 строк). Оба прохода rc=0, ни одного traceback/пустого ответа.

## Как гонялось
- offline: `WALKS_OFFLINE=1` (+`--offline` не нужен), `WALKS_FEEDBACK`/`WALKS_STATE_FILE` изолированы.
- AI: `WALKS_ENV=demo` (подхватил untracked `демо-окружение (untracked)`), цепочки переопределены ТОЛЬКО на `openai-звено` ссылки:
  - `LLM_CHAIN=открытая модель с открытыми весами (4 звена)`
  - `LLM_INTENT_CHAIN=открытая модель с открытыми весами (2 звена)`
  - плюс `WALKS_DEMO_PIN= WALKS_CACHE_PIN= WALKS_LLM_CACHE=off WALKS_DEMO_CACHE=off` — демо-кэш и replay отключены, все ответы живые (cached=False проверен).
- Координаты точек (центр, левый берег/Экспо, вокзалы, аэропорт, Хан Шатыр, Коктал, Шанырак, Ботсад) сверены с Nominatim (UA `astana-walks-fuzz/0.1`, ≥1 c между запросами).

## Ключевые паттерны (генерализуемые)

1. **Словарный разбор не видит доменных слов без готовых правил** — «хочу посмотреть на город сверху», «что посмотреть в вашем районе», «first day in Astana», «вегетарианское», «шашлык» дают пустые категории/keywords → кафе и фастфуд. В AI-режиме те же запросы распознаются, но часто упираются в отсутствие данных (viewpoint) или в невалидный ответ ИИ.
2. **ИИ-текст противоречит карточке** (класс honesty): халяль приписана стейк-хаусу и пабу; «wheelchair accessible… is marked as accessible» при заметке «not stated in the data»; «открыто до полуночи» без источника. Модель свободно утверждает то, чего нет в карточке.
3. **Игнорирование явных ограничений**: халал (kk) распознан в keywords, но не повлиял ни на подборку, ни на текст; «быстро, у меня час» → 778 м; «недорого, студентский бюджет» → 1,9 км пешком, на месте 14 мин; из мечети советуют саму мечеть.
4. **Ложные друзья/ложные триггеры лексикона**: «ничего fancy» → budget=high; «на коляске» → with_kids=true; «кешкі ас» → ночной режим с барами; «не туристам» → туристический набор с Байтереком.
5. **Погодный оверрейд** только через числовой `--weather` — слова пользователя («-25, холодно») в разборе не участвуют; при живой open-meteo (+9°) холод в тексте не отражён.
6. **Мини-маршрут не согласован с карточками**: совет вне маршрута (Японский сад), два места одной сети (Starbucks×2), три одинаковых «Детская площадка» подряд.
7. **ИИ за пределами радиуса**: добавляет далёкие места (Фуд Солюшн 778 м, Японский сад 1828 м) и режим «car» без запроса пользователя (аэропорт, 15 км радиус, музей в 14,6 км).

## Замечания по процессу
- В AI-режиме без переопределения переменных демо-кэш (`демо-окружение (untracked)` включает `WALKS_CACHE_PIN=1`) подсовывает записанные ответы: обязательно глушить `WALKS_DEMO_CACHE=off WALKS_LLM_CACHE=off WALKS_CACHE_PIN=` (иначе «cached=True» и не те цепочки).
- 3 из 20 AI-запросов на viewpoints/необычное упали в «ответ ИИ не прошёл проверку (нет валидных poi_id)» — фолбэк сработал, но пользователю достаётся кафе вместо запрошенного типа: часть класса data (нет точек), часть — валидации.
