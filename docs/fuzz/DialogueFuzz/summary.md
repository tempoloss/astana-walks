# DialogueFuzz — 40 диалогов × 2 режима (offline / AI), 2026-10-17

Диалоговый раунд фаззинга: 40 диалогов по 1–4 реплики (129 реплик, из них 89 уточнений), каждая реплика прогоняется в двух режимах (офлайн / ИИ) в одной цепочке состояния диалога. Протоколы: `dialogues.jsonl` (сценарии с координатами, временем и уточнениями); сырые выдачи и тайминги не копировались (объём), сводка собрана из них 17.10.2026.

## Как гонялось

- offline: `WALKS_OFFLINE=1`, изолированный файл состояния диалога на сценарий (`states/state_<id>.json`), общий файл обратной связи.
- ИИ: `WALKS_ENV=demo` (демо-окружение, untracked), цепочки переопределены только на openai-звенья к открытой модели с открытыми весами; демо-кэш и replay отключены, все ответы живые (cached=False проверен).
- Реплики-уточнения идут через `--follow-up` в цепочке: базовая реплика `--keep-state`, затем каждое уточнение в том же состоянии. Порядок прогонов: сначала вся офлайн-цепочка, затем вся ИИ-цепочка (общий файл состояния диалога).

## Состав

- Персоны: расплывчатые входы 3 («привет», «скучно»), пенсионеры 4 (опечатки, медленный набор, «на лавочке»), подростки 4 (сленг, без пунктуации), голосовой ввод 2, транслит 2, шала-казахский 3, ломаный en/ru туриста 4, нетерпеливые 2, растерянные 2, реакции на выданный список 5 («не то», «дорого», «далеко», «где туалет», «открыто сейчас?»), только благодарность 2, оффтоп 2 (погода, курс валюты), родители с коляской 2, коляска/доступность 3.
- Языки: ru 33, kk 4, en 3. Стартовые точки: Байтерек 33, Ару Сити 7.

## Результаты

- 258 прогонов (129 офлайн + 129 ИИ), rc=0 во всех — ни одного краша и ни одного traceback.
- Вердикты по репликам (последний прогон каждой): OK 112, ENV-INTENT 14, ENV-GEN 3.
- Диалогов хотя бы с одной не-OK репликой: 15 из 40.
- ENV-GEN (3): ответ ИИ не прошёл проверку (нет валидных poi_id) — честный фолбэк на шаблон: d04a «аптека рядом нужна», d07a «где кофе взять рядом срочно», d38a «аптека работает» (аптек как категории в данных нет).
- ENV-INTENT (14): расхождение офлайн- и ИИ-ветки на уточнениях без смены намерения («спасибо», «не понял», «а оно сейчас открыто?», «куда сходить на коляске», «курс доллара какой»…). В 9 из 14 ИИ-подбор выбрал другие места из того же пула кандидатов при том же намерении (шаблон берёт топ-3 по ранжированию, модель — свои 1–3); в 2 — ИИ дополнил разбор категориями/keywords; в 2 — сменил язык (kk) или бюджет времени; в 1 — оба звена разбора не ответили (timeout + исчерпан бюджет запроса), сработал фолбэк.
- Латентность (последний прогон каждой реплики): офлайн медиана 586 мс, p90 767 мс, максимум 856 мс; ИИ медиана 7,6 с, p90 10,1 с, максимум 13,8 с.
- Крашей, выдуманных мест и отказов на ровном месте нет; фолбэки подписаны «[шаблон из данных]».
