# FuzzRound2 — 60 новых запросов × 2 режима (offline / AI), 2026-10-17

Персоны, не покрытые в round-1: пожилые, иностранные студенты (en, китайско-английские, турецко-английские), курьеры на перерыве, диет-ограничения (вегетарианцы, безглютеновые, кошер, строгий халяль), болельщики до/после матча (Астана Арена / Барыс Арена), семьи с малышами (ТРЦ), ночные смены 03:00–05:00, расплывчатые описания мест («тот большой шатёр», «башня с шаром», «золотая юрта», «дерево жизни»), многошаговые планы («сначала поесть, потом музей, до 18:00»), 6 follow-up-пар через `--follow-up` (r41–r46: а поближе / а без алкоголя / а если с ребёнком / а на час дольше / something else / жақынырақ).

- Запросы: `queries.jsonl` (60; ru 24 / kk 18 / en 12 / zh_en 4 / tr_en 2 — доля ru:kk:en ≈ 40:30:30 от общего числа). Ни один запрос не повторяет round-1 (проверено скриптом против FuzzTourist + FuzzLocal).
- Сырые выходы: `outputs/<id>[_a|_b]_<mode>.txt` (132 файла: 54 одиночных + 6 follow-up-пар по шагу a/b), тайминги `timing.jsonl`.
- Проблемы: `findings.jsonl` (56 строк). Оба прохода rc=0, ни одного traceback/пустого ответа/крэша.

## Как гонялось
- offline: `WALKS_OFFLINE=1`, изолированные `WALKS_FEEDBACK`/`WALKS_STATE_FILE`; follow-up — по два шага с `--keep-state`/`--follow-up` и пер-парным state-файлом.
- AI: `WALKS_ENV=demo` (untracked `демо-окружение (untracked)`), цепочки переопределены только на `openai-звено` ссылки; `WALKS_DEMO_PIN= WALKS_CACHE_PIN= WALKS_LLM_CACHE=off WALKS_DEMO_CACHE=off` — кэши выключены, все ответы живые (в выдачах «cached=False» не встречается).
- Координаты якорей (Астана Опера, вокзал Астана, Астана Арена, Барыс Арена, Хазрет Султан, Нацмузей, КБТУ/Expo-кампус, MEGA Silk Way, Коктал-2, Эмираты/АРУ) взяты из самих POI датасета, чтобы советы были проверяемы против карточек.

## Состояние цепочек в AI-режиме (важно для интерпретации)
Живой шлюз в этот день был нестабилен:
- разбор (intent-chain): 14 из 66 AI-прогонов — «ИИ не уточнил разбор» (timeout 5.3 с);
- генерация: 21 из 66 — «все звенья цепочки недоступны» → честный фолбэк на офлайн-шаблон;
- 4 AI-прогона (r16, r28, r50, r55) — «ответ ИИ не прошёл проверку (нет валидных poi_id)»;
- латентность AI: медиана 11.0 с, p90 20.3 с, max 23.1 с (8 прогонов > 20 c); offline: медиана 0.53 с, max 0.59 с.
Поэтому часть AI-находок — это поведение фолбэка, а не LLM; такие помечены.

## Ключевые паттерны (генерализуемые)

1. **Диет-ограничения почти не влияют на подбор.** Вегетарианский запрос → «KAL'BI meat house» и «Shashlyk Pub» (r76, оба режима), keywords распознаются, но ранжирование их игнорирует; Veggie Кафе 108 есть в данных (overture_category=vegetarian_restaurant) и в offline-выдачу не попадает (r11). Для gluten/kosher нет даже оговорки «диет-пометок в данных нет» (в отличие от халяль, где round-1 фиксы дают честную строку «Ни у одного из найденных мест нет отметки халяль» — r18/r50/r84, это работает).
2. **ИИ-текст против карточки остаётся главным риском honesty.** Критично: целиакия → «блюда стейк-хауса естественным образом не содержат глютена» (r14); KAL'BI «including vegetarian options» (r12); тройное «подходит для веганов» без данных (r51); «breakfast at 5 am» для мест с неизвестными часами (r30). Отдельный позитив: r63 — ИИ говорит о доступности только там, где wheelchair=yes в данных (round-1 фикс работает на реальных атрибутах), и «Wi-Fi is listed in OSM» соответствует internet_access=wlan.
3. **Словарь intent для «новых» фраз системно беднее LLM.** Offline не распознаёт: лестницы→accessibility (r01), kk «баласымен»→with_kids (r25), kk «бар» в заимствованиях (r22), «write thesis»→wifi (r07). LLM закрывает эти пробелы, когда шлюз жив.
4. **Мини-маршрут при жёстком бюджете не оптимизируется под «уложиться».** 20 минут → маршрут 24/20 (r09), 15 минут → 24/15 и 26/15 (r72); система честно пишет «НЕ укладывается», но всё равно выдаёт 3 места и маршрут вместо одного ближайшего. Кофейни вместо еды при budget=low и «дәмді тамақ» (r10).
5. **Follow-up работает по механике, но не по смыслу.** «а поближе» (r41) и «жақынырақ» (r45) корректно сужают радиус с честной пометкой [чуть дальше]; «без алкоголя» (r42) отсеивает 20 баров; «на час дольше» (r46) двигает бюджет. Но «а если с ребёнком» (r43) — выдача не меняется ни на пункт (Buddha-Bar остаётся), «something else» (r44b) снова показывает Starbucks из прошлого ответа.
6. **Многошаговые планы сводятся к набору точек без порядка и полного покрытия этапов.** «сначала поесть, потом музей» (r37 offline): 3 еды, 0 музеев; «first lunch, then a museum» (r39 ai): маршрут музей→обед — порядок обратный запросу; «мечеть → халяль → парк» (r38 ai): три достопримечательности, еды и парка нет.
7. **Ночные запросы — худшая зона.** «что открыто в 4 утра» → категории без restaurant/fast_food, выдача: Тайказан (памятник) + 2 спортобъекта (r28, критично в offline); ТЦ с неизвестными часами ночью в выдаче без явного риска (r29); «горячее» не искомо (r27).
8. **Расплывчатые описания: LLM угадывает ориентир, но подменяет объект молча.** «башня с шаром» → Байтерек верно (r32, r35), но «смотровая площадка» не подтверждена данными; «большой шатёр» → Nur Alem (сфера, не шатёр) (r31); «золотая юрта» → Байтерек (r33); «дерево жизни» → 25-летие Независимости (r36); «sphere building, can you walk inside it?» → два парка, вопрос не отвечен (r34). Информационного запроса («что это?») в системе нет — на любой vague-вопрос отвечается подбор мест.
9. **Латентность AI-цепочки деградирует UX**: p90 20 с, 8 прогонов > 20 с; «недавний сбой, ещё 120 с» карает последующие запросы после одного timeout (r58: 15+ с до исчерпания бюджета).
10. **Честные заметки round-1 удерживаются в offline**: «часы работы неизвестны», «координаты совпадают с Overture», «впритык по времени», «нет отметки халяль» — систематически присутствуют; халяль больше не приписывается пабам/стейк-хаусам (регресс round-1 F07 не воспроизведён), «на коляске» не путается с детьми (регресс F03/F04 не воспроизведён).

## Замечания по процессу
- Обязательное глушение демо-кэша как в round-1 (`WALKS_DEMO_CACHE=off WALKS_LLM_CACHE=off WALKS_CACHE_PIN=`) — иначе подсунутся записанные ответы.
- Нестабильный шлюз в день прогона: 21/66 AI-генераций ушло в фолбэк — для чистоты сравнения с round-1 AI-числа (генерация) стоит перепроверить при живом шлюзе; intent-разбор и офлайн-режим не затронуты.
