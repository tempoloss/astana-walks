# Сценарий демо-видео: 3 минуты и нарезка на 30 секунд

> **Сценарий написан по текущему веб-интерфейсу** (`cd app; uv run poe demo`, порт 8600; второй запуск — порт 8601 через `uv run python -m web --port 8601`, третий — порт 8602). Streamlit удалён. Кадры всех экранов (телефон 390×844 и 360×740 с жестами пальцем: лист в трёх положениях, тап по пину, подробности, клавиатура, меню; ноутбук 1440×900 и 1920×1080; 13 записанных ответов, kk, Город, Данные, офлайн) снимает `app/scripts/ui_tour.py` в `app/.local/ui-shots/`. Запись видео приостановлена, `record_demo.py` и `cut_demo.py` удалены.

Для YouTube (ТЗ: «загруженное демо на Youtube и доступ по ссылке»). Видео должно работать без нас: жюри отбирает топ-10 только по материалам. Голос — Ануар, коротко и по делу. Казахские реплики проверяет носитель (список в `docs/pitch/strategy.md` §6).

**Раскладка экрана на 1920×1080.** Слева вверху плашка: «Анық», разделы «Ассистент / Город / Данные / Память», переключатель «Қаз / Рус / Eng», пять плиток-примеров с мини-картами и строка времени «сейчас · 14:00 / через час / вечером» (в закреплённом демо «через час» и «вечером» недоступны). Справа внизу панель ответа: она растёт вверх; внизу в ней «Вы здесь: …» с кнопками «Изменить» и «Условия» и поле запроса. Слева внизу легенда карты «Обозначения» с подписью карты: на первом экране открыта, под ответом свёрнута в одну строку. Названия разделов меняются вместе с языком, сам переключатель «Қаз / Рус / Eng» и «Анық» — нет. Карта при выборе места не двигается.

## 0. Подготовка

**Все запуски идут с закреплёнными условиями демо (`WALKS_DEMO_PIN=1`).** Время закреплено: понедельник 19.10.2026, 14:00, ночной сценарий в 23:00. Погода обычная, 10 °C. Если в тексте запроса есть «мороз», «холод», «аяз» или «суық», ощущается −25 °C. Пешие отрезки берутся из `data/walk_cache.json`, отметки людей — из отслеживаемого сида `data/city_feedback.json` (`app/walks/demo_pin.py`). Поэтому запись в любой день и час повторяет репетицию. Интерфейс об этом молчит (это не режим стенда, а условия записи), поэтому в ролике время и погода названы вслух. Выбор времени и погоды («Условия» → «Другое время / погода») в закреплённом демо скрыт.

## 3. Если что-то пошло не так

- Ответ шагового запроса пришёл не из записи (текст другой, чем на репетиции), идёт живой вызов или шаблон. Значит, разбор или данные поменялись после прогрева, либо запрос набран не дословно: остановить запись, запустить `warm_cache.py --verify-only`, проверить текст и при необходимости перезапустить `warm_cache.py`.
- В ответе нет строки «Ощущается как -25°C: сначала места в помещении». В тексте запроса нет «мороз» или «холод»: ввести запрос заново.
- Язык ответа «прыгнул» сам. До первого клика переключатель следует за языком последнего запроса: нажать нужный язык явно.
- В разделе «Город» не видно ячеек. Слой грузится после открытия раздела; карта открывается на Астане (масштаб 11, `app/web/static/js/city.js`). Если всё же не видно — приблизить колёсиком или «+» на Астану до ячеек.
