# Как устроен RAG

Места выбирает код, модель только объясняет выбор. Каждое утверждение в ответе опирается на запись из базы мест.

**1. База.** `data/poi.enriched.json`: 2 294 места Астаны из OpenStreetMap, Overture Maps, Wikipedia/Wikidata и официальных сайтов заведений (`docs/figures.md`, §1; записи об одном месте слиты в одну). У каждой записи есть источник, лицензия и дата снимка. Сбор автоматизирован (`python -m collect.build`), покрытие полей — в `docs/figures.md`.

**2. Поиск, без модели.** Запрос разбирают правила ru/kk/en, модель может только добавить категорию или флаг. Поиск структурный: радиус считается из бюджета времени (пешком 4.5 км/ч, 40% бюджета на дорогу туда и обратно), дальше фильтр по категориям, совпадения по названию и тегам, часы работы на момент прихода (закрытые исключаются, неизвестные остаются с пометкой), погода, воздух, закат, праздники и слияние точек одной сети. Эмбеддингов нет: настоящее описание (тег OSM или Wikipedia) есть у 2.3% мест (`docs/figures.md`, §4), семантически искать почти не по чему.

**3. Что получает модель.** Один вызов генерации на весь ответ: факты 1–3 кандидатов (название, категория, теги, описание, состояние часов, расстояние и время, посчитанные кодом), разобранный запрос, округлённая точка и условия. Этот JSON в интерфейсе не показывается: он остаётся в поле `explain` ответа `/api/turn` и в CLI.

**4. Генерация и проверка.** Модель пишет «почему» и «что делать» на языке запроса по схеме. Код отбрасывает места не из списка кандидатов, сам подставляет расстояния, время, часы и источник, вырезает фразы про «открыто сейчас» и ограничивает уверенность качеством данных. Свободный совет помечен «Идея ИИ».

**5. Без модели.** Цепочка Gemini → Gemma → (по желанию) любой OpenAI-совместимый провайдер, на весь запрос не больше 15 с. Если не ответил никто, текст собирается шаблоном из тех же фактов. Офлайн-режим не делает ни одного сетевого запроса. Места и маршрут во всех режимах одинаковые.

**6. Обратная связь.** Анонимные отметки людей («был: открыто», «есть розетка») — отдельный слабый уровень доказательств: они затухают со временем и не переписывают данные.
