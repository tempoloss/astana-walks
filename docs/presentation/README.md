# Как показывать деку «Анық»

Три файла, одна и та же дека из 15 слайдов (14 на 5–7 минут речи и запасной слайд «Источники»):

| файл | зачем |
|---|---|
| `deck/slides.html` | основной вариант: анимированная дека в браузере, работает без сети |
| `deck.pptx` | если на площадке только PowerPoint: анимированные слайды встроены как видео, текст речи в заметках |
| `deck.pdf` | для формы сдачи: статичные финальные кадры всех 15 слайдов, включая «Источники» с авторами фото и снимков |

Текст к слайдам: `speaker_notes.md` (он же в заметках PPTX и в блоках `notes` в `deck/slides.html`), под каждым
блоком — откуда его факты.

## Из браузера (лучше всего)

1. Открыть `docs/presentation/deck/slides.html` в Chrome или Edge двойным щелчком. Сервер не нужен.
2. `F` — полный экран (ещё раз `F` или `Esc` — выход).
3. `→`, пробел, `PageDown` или щелчок — следующий слайд. Анимация слайда запускается сама: полёт по карте к
   маршруту живого ответа (3), обводка строки вайба (6), счётчики (7, 8, 9), заливка районов (10), рост точек
   4 170 мест по источникам (11). Слайд 4 — слой «Спутник» (снимки Esri) с маршрутом от Байтерека.
4. `←` — предыдущий слайд сразу в конечном виде; `Home` / `End` — первый и последний слайды.
5. Номер слайда в адресе: `slides.html#7` открывает седьмой.

Кликер с кнопками «вперёд / назад» работает, если он шлёт `PageDown` / `PageUp` или стрелки (так делает большинство).

## Из PowerPoint

`deck.pptx`: на каждом слайде картинка во весь лист, на анимированных поверх неё видео, которое стартует само и
крутится по кругу. Заметки — текст выступления и источники. Видео встроены в файл, отдельные файлы не нужны.

## Пересборка

    uv run docs/presentation/deck/build.py --sheet app/.local/deck3_sheet.png

Подробно об исходниках — `deck/README.md`, почему дека так выглядит — `deck/style.md`. Скриншоты стенда снимает
`deck/shots/shoot.py`, проверяет `deck/shots/factcheck.py`; фотографии кадрирует `deck/photos/fetch.py`.
