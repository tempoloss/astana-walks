## Wins (top 5 harvestable additions)
1. **Phone merge for F&B**: `contact:phone` 107 + `phone` 64 (≈150 after overlap) vs shipped `pct_phone` 40.9 % → ~+12 pp phone coverage on 1219 F&B records. Zero schema change — field exists.
2. **Populate already-modeled attributes by re-harvest**: `outdoor_seating` 137, `wheelchair` 53, `internet_access` 52, `smoking` 33 on F&B, plus city-wide `wheelchair` **384** (yes 225 / no 131 / limited 28) — the accessibility ceiling the eval (`step_free`, `wheelchair_unknown_not_flagged`) is honest about today.
3. **`fee` layer**: 187 tagged (109 `fee=no`) → «бесплатно» reasons backed by data (today the claim path sees ~1 F&B hit).
4. **Route-comfort layer (new, not POI)**: benches **673**, waste_baskets **126**, drinking fountains 7, kerbs 71, footway `surface` **1180** / `lit` **572** — one Overpass query each, ODbL, feeds the «почему тут можно идти» narrative.

## Dead / rejected + why
- **`opening_hours:*` variants (105)** — 100 % `opening_hours:signed=no` («hours not signed»), zero schedules; `open_date` 0, deprecated `hours` 0. The 22 % hours hole is NOT closable from OSM variants; `24/7` (358) and `self_service` (7) already inside existing fields.
- **Playground attribute depth** — topic/seasonal/lit/bench/bin = 0; min_age 7, surface 8. Category already fully ingested (332/328).
- **Kids alternatives** — water_park/indoor_play/arcade/pool/theme_park all ≤2 and already in DB; jumping/climbing/trampoline 0.
- **Viewpoint hole** — `tourism=viewpoint` 1 (unnamed, in DB), `man_made=observation` 0, `tower:type=observation` 0: OSM cannot grow viewpoint beyond 1 (confirms recon decision).
- **live_music/music/terrace/children tags on F&B** — all 0; hostels 16 out of scope (no hotel category).
