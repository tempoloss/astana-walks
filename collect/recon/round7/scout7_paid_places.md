## Wins

**Прямой ответ: NONE — ни один стандартный платный self-serve tier не позволяет легально хранить ratings для Астаны.** Ключевые находки раунда:

1. **Foursquare — единственный вендор, который ПРОДАЁТ именно нужные поля как датасет.** Flat-file «Places Premium» содержит `rating` (0–10), `hours` (JSON), `photos`, `price` — «available as add-ons to any standard country or region package at an additional charge» (rendered https://docs.foursquare.com/data-products/docs/places-pro-and-premium). Но лицензия flat-file — **CONTRACT** («Early Access Only», форма Contact Us; публичного retention-текста нет → `[не прочитано полностью]`). API-путь исключён: «Pay as You Go & Sandbox Customers: **no caching permitted**».
2. **Самое дешёвое легальное место-хранение place-данных — Stadia Maps Standard, $80/мес** — но в выдаче нет ни rating, ни hours, ни photos (sources: OSM/OA/WOF/GeoNames/FSQ-OS) → хранить нечего, кроме того, что мы уже берём из OSM бесплатно под ODbL.
3. **Mapbox отдаёт rating/hours/photos/price в Search Box API (~$153/мес при 90k), но хранить запрещено** («Customer shall not export, store, or cache Temporary Geocodes»); permanent-режим у Search Box отсутствует — только у Geocoding v6, который POI-данных больше не отдаёт.
4. **HERE**: hours/contacts — 30-дневный кэш; Tripadvisor-рейтинги — «BETA, RESTRICTED», т.е. по индивидуальному контракту.

Итог для продукта: **верdict «ratings un-storable» остаётся в силе для всех self-serve платных tier'ов**. Реальные пути: (а) **CONTRACT** — Foursquare Places Premium flat-file (пакет KZ + rich attributes), цена по запросу — это единственная документированная дорожка с реальными рейтинг-полями и подтверждённым KZ-присутствием в той же БД; (б) продолжать RUNTIME-паттерн: хранить только IDs (`fsq_place_id` — Foursquare; Yelp business IDs — back-end matching) и тянуть rating/hours/photos в реальном времени. Foursquare Premium runtime ≈ **$1 687/мес** — вдвое-втрое дешевле найденной ранее runtime-оценки Google (~$5 400/мес) при том же наборе полей.

## Dead/rejected

- **Yelp Fusion/Places API** — DEAD для хранения: 24-часовой лимит + запрет «create your own database of business listing information» (цитата выше).
- **Mapbox Search Box** — RUNTIME only: нет permanent-режима для POI, POI Results только с Mapbox Map, хранение Temporary Geocodes запрещено.
- **Geoapify** — STORE-paid легален, но данные = OSM (ODbL): no rating/photos/price; ничего нового против прямого OSM-пайплайна.
- **Stadia Maps** — STORE-paid легален ($80/мес), но поля rating/hours/photos отсутствуют в источниках.
