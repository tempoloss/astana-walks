# Стрит-левел фото Астаны: KartaView / Mapillary / альтернативы — живые пробы 2026-10-18

Цель: найти стрит-левел фото Астаны без платного договора. Все пробы ниже выполнены 2026-10-18, keyless, с UA `astana-walks-recon`. DNS-ограничение машины учтено: хосты мерялись через `dns.google/resolve` + прямые HTTPS-запросы (все хосты ниже резолвились обычным curl — `--resolve` не понадобился).

## KartaView — метод замера (воспроизводимый, keyless, ~10 мин)

1. **Число фото**: сетка GET `https://api.kartaview.org/2.0/photo/?lat={lat}&lng={lng}&radius=500&page={n}` по Астане (шаг ~450–650 м), дедуп по `id`, ответ: `{"result":{"data":[{id, lat, lng, heading, dateAdded, sequenceId, fileurlTh, fileurlProc, …}], "hasMoreData":bool}}`. Прямая ссылка на кадр: `https://storage13.openstreetcam.org/files/photo/2024/8/8/proc/<hash>.jpg` (проверено 200, 1.06 МБ; thumb-вариант `th/` — 200, 14 КБ). Поля `username` в ответе **нет** — только числовой `from`/`userId` (атрибуция через `/2.0/sequence/?id=…` → `userId`).
2. **Число последовательностей**: coverage-тайлы `GET https://api.kartaview.org/2.0/sequence/tiles/{x}/{y}/{z}.json` (**порядок x/y/z**, не z/x/y!) по bbox 51.10–51.16 / 71.39–71.47; на z16 (285 тайлов, 200 у 245, 40×429) → 840 уникальных треков (дедуп по закруглённым концам). PNG-вариант (`…/tiles/z/x/y.png`) — **заглушка** (один и тот же 2 222-байт файл md5 `ecca8331` для любой точки мира, включая Вену и Лондон — coverage-картинки не несёт).
3. **Ловушки**: (а) `?bbox=` отвечают «Restricted access!» на обоих хостах (`api.kartaview.org` и `api.openstreetcam.org` — это один бэкенд, 200/одинаковые тела) — bbox работает только из авторизованной сессии веб-приложения; (б) radius жёстко ≤ 500 м; (в) rate-limit: ~1 req/сек держится, параллель ≥2 потоков ловит 429; (г) `main.37500d86f90dd0a752a5.js` на kartaview.org содержит встроенный apidoc (5 форматов coverage-тайлов: png/json/…) — там же реальные примеры, в т.ч. `GET https://api.openstreetcam.org/2.0/photo/?lat=…&lng=…&radius=500`.

## Mapillary — точный путь к замеру (зарегистрировать → запросить → что вернёт)

1. Зарегистрировать приложение: https://www.mapillary.com/dashboard/developers (аккаунт Meta/Mapillary, бесплатно, без биллинга) → «client token» формата `MLY|<app_id>|<secret>`.
2. Coverage-замер по векторным тайлам (покрытие = число sequence-фич): `GET https://tiles.mapillary.com/maps/vtp/mly1_public/2/{z}/{x}/{y}?access_token=MLY|…` (docs: слой `sequence`, зум 6–14, свойство `sequence_id`, `captured_at`, `is_pano`, `quality_score`; лимит 50 000 тайлов/сутки). Для Астаны: тайлы z12–z14 по bbox 71.39–71.47 / 51.10–51.16 (~20 тайлов z14), декодировать MVT (mapbox-vector-tile), посчитать уникальные `sequence_id` в слое `sequence` и точки слоя `image` (зум ровно 14).
3. Точное число фото: сетка `GET https://graph.mapillary.com/images?access_token=MLY|…&fields=id&bbox=<минLon,минLat,максLon,максLat>` — bbox строго < 0.01°×0.01° (правило от 2026-01-16), лимит 10 000 req/мин, ответ `{"data":[{"id":…}]}`. Точек сетки для города ~360 → покрывается за один день даже при консервативном темпе.
4. Что вернёт при живом покрытии: sequence-фичи с `captured_at` 2016–2026 (в Астане снимали ещё HERE-флит в 2017 — вероятно, покрытие МНОГО больше картавьюшного; карта Mapillary визуально показывает зелёные линии по главным улицам Астаны, но численно это подтвердится только по п.2–3).

## Юридика использования (для приложения-потребителя)

- **KartaView** — можно хранить и показывать в коммерческом приложении: CC BY-SA 4.0 (цитата выше из ToS §«Open Source License»; там же MIT для кода). Требования: атрибуция («Фото: <автор>, KartaView, CC BY-SA 4.0» + ссылка) и share-alike на производную базу изображений — конфликтует с ODbL-кодом ровно так же, как наш OSM-слой, т.е. допустимо. Заслон от «не храни» нет: скачивание через публичный API — лицензированный путь, не скрейп.
- **Mapillary** — read API без публикации данных допустим только как runtime-показ с атрибуцией (логотип + ссылка, §11); хранение срезов/кадров в БД попадает под §5.1 (copy/reproduce) и «data mining … not approved». CC BY-SA на User Content не отменяет платформенные ToS (там же §3.2: «we may provide access … under a separate set of license terms»).
- **Google/Bing** — кэш кадра улицы в оффлайн запрещён дословно (цитаты в таблице). Только runtime + партнёрство.

## Вывод

1. **Хранить легально можно только KartaView** (CC BY-SA 4.0), но покрытие Астаны — сотни фото (423 нижней оценкой), точечные прогулочные снимки 2024–2026, не коридоры. Годится на «фото-иллюстрация к знаковым местам» уровня §15.5, не на стрит-слой.
2. **Mapillary — вероятно, основное покрытие города** (HERE-флит 2017 + крауд), но численный замер упирается в бесплатный client-token (15 минут после регистрации на mapillary.com/dashboard/developers; запросы и лимиты описаны выше). ToS позволяют только runtime-показ с атрибуцией — STORE-слой из Mapillary строить нельзя.
3. **Google/Bing** — кадр улицы кэшировать в оффлайн нельзя (дословные запреты выше); Yandex — нет легального API; Panoramax — 4 кадра на город.
