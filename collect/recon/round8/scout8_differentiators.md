## Wins (топ-3 по effort/дифференциация)

1. **Kazakh-first слой (S).** Изменение в продукте: у каждой карточки — kk-имя из `s_geonims` (№401-V, хранимое) или Wikidata-метка (CC0) поверх RU-имени; kk-локаль получает реальные адреса («көш.», «даңғ.» из `d_geonims_types`), kk-имена праздников (Nager) и kk-описания (Wikipedia CC BY-SA). Число для слайда: «110 → ~300 мест с официальным казахским названием». Killer argument на сцене: «Ни 2GIS, ни Яндекс, ни Google не показывают официальные казахские названия — мы берём их из живого реестра Генпрокуратуры (обновлён 15.10.2026). Для НИЦ, который исследует казахский NLP, мы — витрина их повестки».
2. **Праздничный/событийный контекст Nager.Date (S).** Изменение: строка контекста «сегодня/завтра <праздник kk>» + флаг «в праздник музей может быть закрыт» в подбор (13 праздников 2026 уже в kk, MIT/facts, без ключа, offline-store). Killer argument: «бот знает, что сегодня Наурыз и что завтра День столицы — 2GIS знает только часы».
3. **«Зелёный маршрут»-композит (M).** Изменение: скоринг маршрута по доле зелени (ESA WorldCover 10 м, CC BY 4.0, тайл N51E069) + парков/воды (117/271 OSM ODbL) + бейдж «зелёный/у воды» в карточке; объяснение «why» — «маршрут вдоль Есіля и парков, а не по проспекту». Killer argument: «единственный продукт, который для Астаны считает зелёность маршрута по спутниковым данным ESA, а не „обычно приятное место“» (закрывает и tz2 «тихое место» — данные вместо эвристики).

Запасной (4-й): бейдж-слой доступности (S) на 352 tagged POI с честным «данных мало, вот что известно» — убирает подражание 2GIS, добавляет дифференциацию «честность про данные».

## Dead / rejected
- **OSM scenic-теги как источник живописности**: `scenic=*` = 0, `route=hiking` = 0, `tourism=viewpoint` = 1 — сигнал отсутствует (живые ответы mirror, osm_base 2026-10-18). Остаётся композит.
- **OpenHolidays API для KZ**: `openholidaysapi.org/PublicHolidays?countryIsoCode=KZ` → 200, `[]` — KZ не покрыт (пусть и CC BY-SA 4.0, но данных нет).
- **kk.wikivoyage**: не существует → редирект на incubator, 404 (`https://kk.wikivoyage.org/wiki/Астана`).
- **Commons Wiki Loves Monuments KZ**: категория `Category:Wiki Loves Monuments in Kazakhstan` пуста (members []) — фото/описаний оттуда нет.
- **`surface=ice`, `icycle:*`**: 0 объектов в bbox — зимнее состояние улиц в OSM не размечено.
- **Снегоуборка Астаны**: birge.astana.kz без API (round 4), «Астана таза» без открытого фида — честный data-gap для второго слоя, не фича.
- **data.egov.kz `/api/v4` keyless**: 403 (подтверждено сегодня ещё раз) — только `/api/detailed`.
- **map.gov.kz `openmap:buildings_a`** как основа ветро-солнечного слоя: лицензия не указана → используем Microsoft footprints (CDLA-Permissive-2.0).
