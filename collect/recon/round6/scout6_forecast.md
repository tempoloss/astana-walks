## Wins
**Winner: MET Norway locationforecast 2.0 — the cheapest legal replacement for the Open-Meteo paid tier.**
- Zero new dependencies: same shape as Open-Meteo (one HTTPS GET → JSON point series at exact lat/lon), keyless, commercial use + storage + redistribution explicitly permitted under **CC BY 4.0 + NLOD 2.0** (double-licensed; CC BY 4.0 fits the KZ open-data regime). Attribution one-liner: **«Data from MET Norway»** (+ license link).
- Honesty caveat: MET global runs on ECMWF HRES-derived fields ~9 km post-processed [INFERENCE — payload carries no model tag], vs Open-Meteo best_match for KZ (ICON ~11 km). Both are free-atmosphere model numbers, NOT station-downscaled; expect ±1-2 °C UHI/steppe-cell error in a flat city — same degradation class as switching Open-Meteo model tier, no worse. Wind/gusts degrade most (25 km-class ECMWF cell vs 11 km ICON); 89-step horizon = hourly to +48 h then 6-hourly to +10 d.
- ToS cost: identifying User-Agent with contact email, coordinates truncated to 4 decimals, ≤20 req/s app-wide, honor `Expires`/`If-Modified-Since` — trivial for our per-request weather widget.
- **Chain: YES** — MET Norway (primary, HTTP-only) + NOAA GFS NOMADS subset (secondary, public domain = zero licence risk, cost = eccodes GRIB2 decode ~1.8 MB/bbox/step) is a clean primary/secondary pair; each carries its own one-line attribution (CC BY 4.0 «Data from MET Norway» / public domain «NOAA»), no combined string needed. ECMWF open data is the third fallback (same eccodes lib, AIFS 0.25°, CC BY 4.0). Air overlay stays on NASA GIBS (public domain, keyless) + computed smog index — no keyless CAMS alternative exists.
## Проверка основной нитью (17.10, после отчёта скаута)
- `api.met.no/weatherapi/locationforecast/2.0/compact?lat=51.13&lon=71.43`: с грубым UA (`astana-walks-recon/0.1 contact@example.com`) — **403 nginx**; с корректным (`astana-walks-dev/1.0 https://… contact@…`) — **200, 39 115 Б**, 89 шагов, `updated_at 2026-10-17T11:21:30Z`, сейчас 8.8 °C / 1026.1 гПа / 316°. ⇒ вывод: ключless подтверждён, но **User-Agent сapp-specific строкой обязателен, «generic» отбивается 403** — это первый интеграционный баг, который иначе сядет в проде.
