## Wins (top 5, actionable)
1. **IEM ASOS + aviationweather.gov METAR** — hourly real Astana observations (temp, dew, wind, gusts, visibility, weather codes incl. haze/freeze-rain) since 2000, public domain, two independent mirrors. Fills the «hourly temperature/wind/precip from actual stations» hole. Snapshot daily; commercial use unambiguous.
2. **Meteostat bulk parquet** (data.meteostat.net/hourly/YYYY.parquet, station UACC0) — one 1 GB file/year with cleaned schema; CC BY 4.0; no key. Use as bulk backfill; IEM/aviationweather for real-time.
3. **Kazhydromet NMU + storm pages** — only official source of smog (НМУ) and buran/headwater warnings, explicitly free for commercial orgs under Приказ №267 with mandatory attribution; register at meteo.kazhydromet.kz/database_meteo (free email signup) for the actual Astana station series 2000→present.
4. **NOAA ISD-Lite + GSOD, station 351880** — stable per-year files for climate normals. Note GSOD PRCP/SNDP columns mostly missing for KZ — rely on METAR p01i/wxcodes for precip/snow signals.
5. **Open-Meteo commercial obligation is real and confirmed** — free tier: «You may only use the free API services for non-commercial purposes.» (open-meteo.com/en/terms); commercial = paid plan (API Standard etc.). Cutover of history/observations to public-domain sources (items 1-2) is feasible; forecasts can stay on Open-Meteo paid or Visual Crossing (§10 storage explicitly allowed).

## Dead / rejected
- WMO 352260 as Astana ISD id — wrong; NOAA isd-history carries Astana as USAF 351880 (WMO 35188); explains initial 404s.
- ncei.noaa.gov/data/global-station-daily from the brief — resolves only to a JS S3 explorer; use /data/global-summary-of-the-day/access/ (verified).
- МЧС/ДЧС API/RSS — none public; Darmen has no developer API; data.gov.kz datasets lag >=1 day.
- Tomorrow.io — raw-data storage prohibited without DaaS contract; unnecessary given public-domain options.
- OpenWeather free tier for storage — ODbL share-alike + no explicit storage grant in site ToS; strictly worse than Meteostat/IEM.
- NASA POWER as a current-conditions feed — -999 fill on recent days (MERRA-2 lag); keep only as normals/backup grid.
