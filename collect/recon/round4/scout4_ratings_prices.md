## Wins
1. **Ratings conclusion (hard): ratings can only be RUNTIME.** No provider licenses storage of rating values for self-service/POI use; the only storable rating source (OSM) has 9 objects in Astana, all hotel star-classifications. Any vendor claiming to sell stored ratings (Apify actors, scraping services) is reselling Google/Yelp/Facebook content without rights.
2. **Best legal runtime ratings source: Google Place Details Enterprise, $20/1,000 calls (1,000 free/month)** — one call returns rating + userRatingCount + priceLevel + priceRange + regularOpeningHours + website + phone simultaneously, covering holes #4, #5 and partially #1 in a single runtime lookup. Cheapest alternative: TripAdvisor Content API (5,000 free calls/month; cache only location_id; display logo + deep-link; purge ratings on update).
3. **Prices hole (#4):** no separate source needed — priceLevel/priceRange ride along in the same Google Enterprise call. Independent storable source for attractions: organisations' own tariff pages (Nat. Museum nmrk.kz, Aquarium ailand.kz) — facts, storable under our rule, but published as JPG images → manual transcription for the top ~20 POIs.
4. **Eternal-storage POI licences exist but add nothing for ratings:** LocationIQ ToS allows "store response data forever" for customers; Geoapify allows "Cache/store results with no limits" — both OSM-derived, rating-free. Use only as backup geocoders, not for hole #5.
5. **Hotel stars are storable today:** OSM stars=* (9 Astana objects) under ODbL — ingest for hotels, source-attributed, free.

## Dead / rejected + why
- Geoapify Places as a ratings fix — OSM-derived, no rating field, duplicates our OSM pipeline.
- LocationIQ Nearby — BETA, OSM-only fields (no hours/rating); eternal storage licence irrelevant to ratings.
- HERE — 30-day cache cap + explicit ban on building POI databases; no KZ ratings.
- Mapbox Search Box — "shall not export, store, or cache Temporary Geocodes"; no self-serve permanent flag.
- Stadia Maps — permanent storage needs paid plan; data still OSM-derived, no ratings.
- Restaurant Guru — ToS personal-use + anti-scraping; no official API; no data-licensing product found.
- TripAdvisor for storage — "caching, copying, downloading, storing or indexing content is not permitted"; location_id only.
- Yandex Eda / Choco — scraping explicitly banned; personal non-commercial viewing only.
- kuda.kz — dead connection.
- baiterek.kz — parked/sale domain.
- Yelp Open Dataset — non-commercial only, 0 KZ records.
- Google Local (UCSD) — US-only, 0 KZ records.
- Fourscale/Foursquare check-in research dumps — CC BY-NC: commercial use prohibited.
- OpenCage — geocoding only, confirmed no ratings (as expected).
- Apify/scraper vendors for Restaurant Guru — resell data the vendor does not own; illegal chain.
