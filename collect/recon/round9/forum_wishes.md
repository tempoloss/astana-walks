# Круг 9. «Опенсорс-форумы с пожеланиями» — замер каналом, а не надеждой (18.10)

Вопрос владельца: есть ли форумы, где пожелания по улучшению уже сформулированы людьми.

`GET community.openstreetmap.org/search.json?q=astana&order=latest` (Discourse API, без ключа) + `.json` каждого треда + футер ToS. Старые `forum.openstreetmap.org`/`help.openstreetmap.org` — архив (редирект подтверждён поиском).

## Урожай
6 тредов на «astana», из них релевантных городу **два**, и оба исторические:
- «Aus Astana wird Nursultan» (2019-03, 5 постов) — спор о переименовании в name-тегах;
- «Астана mapping party, 24–26 января 2014» (`posts_count` 120 по search.json) — объявление маппинг-набега.
Остальные — ложные срабатывания по подстроке (Болгария/Польша/Германия). Контрольные прогоны того же API: `q=kazakhstan` — 43 треда, релевантные КЗ — про границы и номенклатуру тегов («Административные границы Казахстана» 2010, «Key int_name must be deprecated» 2026, каспийские границы 2026), ни одного «хочу фичу в картах/прогулках»; `q=Қазақстан` (через `urlencode`, ручной percent-encoding давал ложный 0) — **1** тред: «Сложности совместного картирования в Казахстане» (2017-11, 334 поста, kk-язычный) — kk-текст на форуме есть, но это многолетний диалог мапперов, не доска пожеланий; `q=Астана` кириллицей — 10 тредов, из них по городу тот же mapping-party 2014, остальное мега-треды RU-секции (Garmin/OsmAnd/«Вопросы новичков»), упомянувшие Астану. **Вывод: OSM-форум — не доска пожеланий для Астаны** (измеренно мёртвый канал: живых тредов по городу нет, kk-секции у форума нет вовсе); свежие запросы горожан живут в OSM Notes (уже в проде, §14.6: 300 заметок снапшота, 60 closure-класс) и в сторах приложений.

## Лицензия (для цитат в питче)
Дословной лицензии постов достать не удалось: обе найденные CC-формулировки («Attribution-ShareAlike», «CC BY-SA 2.0») — из футера MediaWiki-страницы `osmfoundation.org/Terms_of_Use`, т. е. лицензируют текст вики OSMF, а не посты Discourse; `site.json`/`about.json` лицензию не вернули, `/tos` — JS-рендер. Дефолт Discourse по ToS площадки — CC BY-NC-SA (не подтверждено дословно ⇒ для хранения тел постов не использовать). Для наших целей канал мёртв по урожаю, так что разбирательство лицензии не нужно: максимум — цитата со ссылкой на тред.

## Итоговый список каналов пожеланий (закрыт, дальше не искать)
1. **OSM Notes bbox** — в проде, ODbL, provenance-сигнал (не покрытие).
2. **App Store KZ RSS** (`itunes.apple.com/kz/rss/customerreviews/id=481627348/sortIndex=0`, без ключа, 200) — 50 свежих отзывов о 2ГИС/Яндекс/Kaspi; цитаты-в-питч, в БД нельзя (Apple ToS).
3. **KazSAnDRA Mapping** — 8 897 kk-отзывов о картах, CC BY 4.0, но gated (401 без принятия условий) — единственный корпус, где пожелания по-казахски; письмо авторам в пост-22.10.
4. OSM-форум — DEAD как источник пожеланий (замер выше).
5. Reddit/Waze/Meta — упираются в коммерч. договоры (§14.6).
